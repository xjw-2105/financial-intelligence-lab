# Financial Intelligence Lab — 产品与视觉规范 v1

## 核心目标

做一套**有电影感、可亲手操作、且完全受真实 MATLAB 实验数据约束**的信贷公平性互动站点。它是课程展示的互动网页，不是银行真实审批系统、不是一个实际商业风控产品。主叙事延续 PPT 的“AI 信贷员三关考核＋补考”与“暂缓独立上岗，继续监督测试”决策。

## 体验动线

### 01 / THE GATE — 实验室入口

- 16:9 舞台感布局。深黑蓝基底、细致网格与深度透视；可选带古典雕塑气质的 3D 守门人装置（仅用自创程序几何或授权模型），流动的线框、透明 HUD 和富有节奏的文字进入。
- 第一屏最多一条命题：**“准确率更高，代表对每个借款人都更公平吗？”**
- 核心事实卡：50,000 条留出测试、9 组已训练配置、随机森林 Full ROC-AUC 0.7376；旁注是历史匿名化数据、非真实审批。
- 明确的“进入审计实验室”按钮和“查看研究边界”。
- WebGL、reduced-motion、低性能设备都能使用高质感静态二维替代，不让 3D 延迟遮挡控件。

### 02 / THE AUDIT — 模型与群体审计

- 左/上固定模型选择（逻辑回归 / KNN / 随机森林）、特征层级（Basic / Enhanced / Full）、指标定义；右侧显示阈值滑块与准确数值输入。
- 中央四格视觉化混淆矩阵：TP/FP/FN/TN 均显示**真实整数**；正类和高风险定义可点开。
- 显示主要的 ROC-AUC、AP（不随阈值改变），以及随阈值改变的 Recall、FPR、FNR 和 Precision。
- 群体切换：F/M、操作性年龄组；性别场景突出两方向的 FPR/FNR 差距，用细线条连接、方向标记和数值标签；年龄场景提示分组是匿名化日期转换下的操作性层级。
- 解释层：当点击某项指标，显示“公式—分母—伦理代价”；数据放在所有动画前面。

### 03 / THE COMMITTEE — 假设成本与部署决策

- 控件：`FP` 假设单位成本、`FN` 假设单位成本，调整时同步计算 `FP × Cost_FP + FN × Cost_FN`。展示成本分项、假设总成本、每1000例的归一化成本。
- 绘制“总体识别能力 / 群体差距”阈值权衡曲线，支持点击离散工作点将阈值写回控制区；必须使用真实预计算点。
- “委员会决议”卡片：暂缓独立上岗，继续人工监督与时间稳定性审计。决议是**本研究给出的课程情景建议**，不是已证明的实际银行监管决定。
- 最后一屏显示数据局限：尚未有真实拒贷结果、真实成本来源、完整客户级隔离与时间成熟期验证。

## UI 视觉设计系统

- **总体风格**：Neo-Classical Cyber Finance — 金融研究机构气质 + 古典雕像/石质纹理的克制引用 + 现代精密仪表。
- **色彩**：背景近黑蓝 `#080C16`；次层面板 `#111928`；文本暖白 `#F2F4F7`；次文本 `#A5AFBF`；科技蓝 `#7CC5F8`；极少量古铜色 `#CCB48E` 表示“审议与责任”。红色只用于错误成本/风险强调，不用于所有装饰。
- **排版**：数字大而克制，建议等宽 tabular numerals；标题现代无衬线，局部英文字母 spaced-caps。中英文都可读，中文为主，英文只作场景标识。
- **布局**：1440px 桌面展示优先，但 1366px 和笔记本 16:10 不溢出，手机降级也可操作。统一 8pt spacing 系统，圆角轻量，图表必须有刻度、单位和悬浮精确值。
- **动画**：入口一次性电影式 3D；其它位置最多 200–400ms 微转场。滑块变化应立即更新整数，不以卷动数字动画掩盖真实变化。尊重 reduced-motion。
- **视觉主角**：概览的 3D 场景最多一处；操作页面以精确图表、精炼的信息层级、优秀留白形成品质感，避免霓虹灯、粒子、玻璃卡片泛滥。

## 三个必须可演示的故事（教师操作剧本）

1. **Accuracy 陷阱**：本测试集中正类 1,054/50,000；全部预测无违约可以得到 97.892% Accuracy，却没有识别任何违约者。
2. **模型与特征升级**：切到随机森林 Full，ROC-AUC 为 0.7376；按冻结 FPR10 阈值显示 TP 333、FP 4,188、TN 44,758、FN 721。注意说明 AP=0.0705，不宣称“自动审批成功”。
3. **成本与公平权衡**：拖动离散阈值观察 F/M 的不同错误方向，再调整假设 FP/FN 单价，展示总成本与公平性无法由一个数字概括。

## 数据展示规则

- 主指标均来自真实 V3 测试汇总，不能拿 V3.1 开发集指标伪装作测试集成绩。
- 仪表板 **不是实时 MATLAB 训练**。用户交互是对冻结模型分数的阈值回放。
- 预测分数未经过证明的概率校准，标签使用“模型风险分数”而非“违约概率”。
- 未知的成本值必须标注“假设”，不得填银行真实金额或宣称实际 ROI。

## 开发验收

最少录屏或截图包括：入口 3D/2D 两种状态、模型切换、模型 Full 随机森林冻结阈值、F/M 差距、年龄分组、成本变化、无 WebGL/减少动画两种回退；必须有本地浏览器无网络冷启动与 console 无错误证据。
