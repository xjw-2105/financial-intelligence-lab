# 源与研究解释限制

本任务基于用户已有《科学计算与 MATLAB 应用》课程项目 V3 / V3.1 冻结结果，以及 2026-11-22 Codex 的 GitHub 技术选型报告。

- V3 测试集为 50,000 个案例，1,054 个违约正类，时间周 83–91；有9组模型×特征组合。此次聚合 JSON 从 V3 各 `results/*_test.csv` 提取而来，用于本地原型，不包含逐笔案例。所有九组 FPR10 混淆矩阵与同次 MATLAB `results/performance.csv` 精确对账通过。
- V3.1 的固定配置和训练样本量控制是 **开发验证证据**，不应混同 V3 冻结测试表现。
- 年龄因匿名化日期转换仅可作操作性年龄分层；性别 F/M 也不作为法律意义上身份的确认。
- 本数据缺少真实审批决策、拒贷记录、客户持续ID，以及实际信贷损失成本。网页不是银行风控生产系统；成本可视化只能用明确标注的假设单位成本。
- 本地原型 JSON 由 Python 从原 MATLAB 保存结果二次计算；这是开发和核验手段，而非“已经 MATLAB 原生直接导出”。正式演示要由本地 MATLAB 再导出和校验。
- 聚合输出是展示数据，不等于原始 Kaggle 数据集获得任何公开再分发授权。若上传公网，应先确认授权与适用条款，并做更严格的数据披露审计。
